# Day 1: Rust Basics

Reference: [The Rust Programming Language Book](https://doc.rust-lang.org/book/)

## Topics to Learn (from Chapters 1-3)

- **Installation**: Ensure Rust is installed via rustup.
- **Hello World**: Create and run a simple program.
- **Variables and Mutability**: `let` keyword, mutability with `mut`.
- **Data Types**: Scalars (integers, floats, booleans, characters).
- **Functions**: Defining functions with parameters and return types.
- **Comments**: Single-line (`//`) and multi-line (`/* */`).
- **Control Flow**: `if` expressions, loops (`loop`, `while`, `for`).

## Instructions
- Run the code with `cargo run` (assuming Cargo project, or `rustc main.rs && ./main`).
- Experiment: Modify variables, add more data types, create new functions.
- Read the docs for each topic to understand deeply.
