# Day 2: Ownership, Borrowing, and Lifetimes

Reference: [The Rust Programming Language Book](https://doc.rust-lang.org/book/)

## Topics to Learn (from Chapters 4-10)

- **Ownership**: Rules (each value has one owner, one owner at a time, value dropped when owner goes out of scope).
- **References and Borrowing**: Immutable and mutable references, dereferencing.
- **Slices**: String slices, array slices.
- **String Type**: Details on Strings vs &str.
- **Lifetimes**: Preventing dangling references, lifetime annotations.

## Instructions
- Run the code with `cargo run`.
- Experiment: Try moving values, borrowing immutably/mutably, create slices.
- Understand why Rust enforces these rules for memory safety.
